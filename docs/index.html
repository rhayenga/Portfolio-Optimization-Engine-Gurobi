Portfolio Optimization Engine

Mean-variance portfolio optimizer built on Gurobi: quadratic and mixed-integer solves behind a FastAPI service, with market-data estimation of expected returns and covariance, efficient frontiers, and out-of-sample backtests.

View on GitHub Quick start

What it does

  • Maximizes μ'w − (λ/2) w'Σw under a budget constraint
  • Position limits, long-only or long/short, and sector caps
  • Cardinality limits via Gurobi binaries (max_assets, min_weight)
  • Estimates μ and Σ from historical prices, with Ledoit–Wolf shrinkage
  • Efficient frontier sweeps and train/test backtests against equal weight

API

Run it on your machine

Solves run locally — Gurobi academic licenses are host-locked, so the API is not hosted here.

git clone https://github.com/rhayenga/Portfolio-Optimization-Engine-Gurobi.git
cd Portfolio-Optimization-Engine-Gurobi
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000

Interactive docs are then served at /docs on that local port.

Stack

Python and FastAPI, Gurobi via gurobipy, yfinance for price history, pytest with GitHub Actions CI, and Docker packaging for the service layer.
